## Replacement rule

When the school supplies its own photographs, replace these demo sources with official school photography. Do not present the current images as photographs of Bukana Brilliant Schools.

## Format direction

WebP is intentionally not required for this project. For locally bundled production images, **AVIF** is the preferred lightweight format, with carefully sized JPEG fallback where broader compatibility is needed. The current demo sources remain raster JPEG/remote assets so their licensing/source information stays clear.
