# Design Reference

Reference project:
https://github.com/sharonbrainacademy-stack/edupro-school-template

Use this reference for:
- overall school website quality
- page hierarchy
- visual rhythm
- section composition
- school navigation
- academic programme presentation
- admissions presentation
- gallery/news presentation
- footer organization
- responsive thinking

Do not reproduce:
- EduPro branding
- EduPro colors
- EduPro text
- exact layouts
- source code
- React architecture
- admin dashboard implementation

Bukana should have its own visual identity.

Primary color:
#0d8215

The design should feel:
- modern
- trustworthy
- educational
- polished
- parent-friendly
- spacious
- professional

Avoid:
- excessive green backgrounds
- generic SaaS appearance
- excessive rounded cards
- excessive gradients
- visual clutter
- over-animation
- fake statistics
- fake testimonials
- unsupported school claims

Use typography with a clear display/body distinction, strong heading hierarchy and comfortable reading width.

Use imagery thoughtfully. Stock imagery may be used for the demo, but it must not be presented as verified photographs of Bukana Brilliant Schools.
