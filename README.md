# Bukana Brilliant Schools Website Demo

A multi-page school website demo inspired by the visual quality and information architecture of the supplied EduPro reference, while using Bukana's own brand direction.

## Stack
- Static HTML
- Tailwind CSS via CDN for the demo
- Vanilla JavaScript
- No mock backend or framework dependency

## Pages
- Home
- About
- Academics
- Admissions
- School Life / Gallery
- News & Announcements
- Contact

## Brand
Primary color: #0d8215

The color is centralized in the Tailwind configuration and CSS variables so it can be changed later.

## Important demo placeholders
Phone number, email, school address, map and WhatsApp number are placeholders and must be replaced with verified school information before production.
